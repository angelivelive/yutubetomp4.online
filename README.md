# TubeToMP4 - Premium YouTube Converter

A blazing fast, privacy-focused YouTube to MP4 converter built with **Astro 5.0**, **React 19**, and **Tailwind CSS v4**.

## 🚀 Features

- **Zero JS by default**: Uses Astro for maximum performance and SEO.
- **Interactive Islands**: React-based converter widget for smooth interactions.
- **Premium Design**: "Deep Matte Black" & "Vibrant Red" aesthetic.
- **Responsive**: Fully optimized for Mobile, Tablet, and Desktop.

## 🛠️ Tech Stack

- **Framework**: [Astro](https://astro.build)
- **UI Library**: [React](https://react.dev)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **Deployment**: Ready for Vercel, Netlify, or Cloudflare Pages.

## 📦 Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```

3.  **Build for Production**:
    ```bash
    npm run build
    ```

## 🐙 GitHub Setup Instructions

Since this project was created locally, you need to create a new repository on GitHub and push this code to it.

1.  Go to [GitHub.com](https://github.com/new) and create a new repository named `yutubetomp4.online`.
2.  Do **not** initialize with README/license (since we have them locally).
3.  Run the following commands in your terminal (inside this project folder):

    ```bash
    git remote add origin https://github.com/YOUR_USERNAME/yutubetomp4.online.git
    git branch -M main
    git push -u origin main
    ```
